# 근거 문서 데이터

캠코 준법 콕이 근거로 쓰는 문서들이다. 문서 하나가 JSON 파일 하나이고, 조문 단위(`articles`)로 나뉘어 있다.

## 파일 형식

| 필드 | 뜻 |
|---|---|
| `id` | 문서 식별자 (파일 이름과 같음) |
| `title` / `shortTitle` | 문서 이름 / 화면에 쓸 짧은 이름 |
| `category` | `공식 근거`(법령·내규·지침) 또는 `참고 자료` |
| `type` | 법률, 시행령, 내규, 지침, 안내 자료 |
| `effectiveDate` | 시행일(참고 자료는 작성일) |
| `version` | 공포 번호·개정일 등 |
| `source` | 원문을 가져온 곳 |
| `fictional` | `true`면 실습용 가상 문서 (실제 캠코 내규가 아님) |
| `articles[]` | `location`(조문 번호·제목) + `text`(원문, 고치지 않음) |
